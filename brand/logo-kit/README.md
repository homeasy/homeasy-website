# Homeasy logo kit — web (RGB)

Rebuilt from the approved brand sheet (*homeasy_brand_sheet_Chillax_CMYK_print.pdf*) for screen use.

**How it was made**
- **Icon:** redrawn as clean vector geometry, measured from the brand sheet (plate radius, rocker sizes, crossbar, indicator dot).
- **Wordmark:** set in the official **Chillax Bold** font file (Fontshare) and converted to vector outlines, sized and spaced to match the brand sheet. Using the font to create logos/wordmarks is permitted by the ITF Free Font License, and they may be registered as trademarks.
- **Colour:** the logo mark itself is unchanged. Only the dark background is now Deep Navy instead of charcoal, to match the website palette.

## Rules
- Use these files. Never retype "homeasy" in a font.
- Clear space: at least one rocker width on all sides.
- Minimum size on screen: icon 16 px; full logo 120 px wide.
- Don't recolour, stretch, rotate, add shadows or glows, or place the logo on blue or amber backgrounds.

## Before final sign-off
Ask the original logo designer to compare these files with the master artwork (icon proportions and spacing). The wordmark is now built from the real font, so its letter shapes are exact. The designer's master files remain the source of truth.
